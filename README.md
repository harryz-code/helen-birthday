# Helen's 26th Birthday Casino

A casino-style birthday game: 3 spins, 6 games, 6 mystery gifts.

**Play it here: https://harryz-code.github.io/helen-birthday/**

## How it works

1. Pick a table for each spin: Roulette Wheel, Slot Machine, or Russian Roulette.
2. The spin lands on a random game you haven't played yet.
3. Play the game in real life. The host enters the PIN and records whether Helen won.
4. Win, and the gift is revealed. After 3 spins, the Bonus Round reveals every gift.

## Running it

- Online: open the link above.
- Locally: double-click `index.html` (no server or build needed).
- Start over: add `?reset` to the end of the URL.

## Editing

All games, hints, gifts, the host PIN, and the finale message live in `games.js`. Images go in `assets/`.
